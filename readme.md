# Address Synchronization

Проект для сопоставления и синхронизации справочных данных
между  Firebird  и внешним источником cvs файлами г.Одесса

## Project structure

- `docs/` — документация
- `src/` — исходный код
- `data/` — исходные и обработанные данные
- `config/` — конфигурация

## Текущий этап разработки

На текущем этапе реализуется только функциональность работы
с типами улиц.

### Реализуемый функционал

- Просмотр типов улиц.
- Загрузка CSV-файла с типами улиц.
- Проверка формата входного файла.
- Загрузка данных во временную таблицу после успешной проверки.
- Обработка данных в соответствии с правилами проекта.
- Отображение результатов загрузки и текущего состояния данных.
- Поиск и фильтрация типов улиц.

### Заглушки

Для улиц и домов, а также для операций добавления, изменения
и удаления записей, на текущем этапе предусматриваются
только элементы интерфейса без рабочей функциональности.

Реализация этих возможностей будет выполнена на следующих
этапах разработки.
