# Address Synchronization

Проект для сопоставления и синхронизации справочных данных
между  Firebird  и внешним источником cvs файлами г.Одесса

## Project structure

- `docs/` — документация
- `src/` — исходный код
- `data/` — исходные и обработанные данные
- `config/` — конфигурация
