## Правило сопоставления:

#### Для S_INPUT_VIDUL
1. Нормализовать `S_INPUT_VIDUL.SHORT_NAME`.
2. Сравнить с нормализованным `S_VIDUL.NAME_UA`.
3. Если найдено одно соответствие, записать `S_VIDUL.ID` в `FK_id_VIDUL`.
4. Если соответствие не найдено или найдено несколько вариантов,
   оставить `FK_id_VIDUL` пустым для дополнительной проверки.

 #### Для S_INPUT_ULIC

1. Найти соответствующий тип улицы через
   `S_INPUT_ULIC.EXT_TYPE_ID` и `S_INPUT_VIDUL.FK_id_VIDUL`.
2. Нормализовать `S_INPUT_ULIC.NAME`.
3. Сравнить с `S_ULIC.NAME_UA` среди улиц подходящего типа.
4. Если найдено одно соответствие, записать `S_ULIC.ID` в `FK_id_ULIC`.
5. Если соответствие не найдено или найдено несколько вариантов,
   оставить `FK_id_ULIC` пустым для дополнительной проверки.
