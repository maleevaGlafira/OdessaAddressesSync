# Data Flow

## Назначение

Документ описывает текущий поток обработки данных при синхронизации
внешних CSV-файлов с данными Firebird.

На текущем этапе рассматривается синхронизация типов улиц и улиц.

## Текущий поток данных

```text
s_vidul.cvs ──┐
              ├─→ входные данные → сравнение с Firebird → результат сравнения
s_ulic.cvs ───┘

Firebird S_VIDUL ──┐
                   ├─→ сравнение
Firebird S_ULIC ───┘


s_vidul.dom - → записать в Firebird 
```
 
## Этапы
Получить внешние CSV-файлы.
Прочитать данные CSV.
Прочитать соответствующие данные из Firebird.
Подготовить данные для сравнения.
Сравнить данные внешнего источника с Firebird.
Определить различия:
новые объекты;
изменённые объекты;
отсутствующие объекты;
объекты, для которых требуется дополнительная проверка.
Сформировать результат сравнения для дальнейшей обработки.

Соответствия между идентификаторами внешнего источника и идентификаторами
Firebird пока не определены.

Правила определения соответствий, обработки новых объектов и записи
изменений в основную БД будут определены на следующих этапах проекта.
