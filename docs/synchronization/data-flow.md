# Data Flow

## Назначение

Документ описывает текущий поток обработки данных при синхронизации
внешних CSV-файлов с данными Firebird.

На текущем этапе рассматривается синхронизация типов улиц и улиц.

## Текущий поток данных

```text
s_vidul.csv ──┐
              ├─→ входные данные → сравнение с Firebird → результат сравнения
s_ulic.csv ───┘

Firebird S_VIDUL ──┐
                   ├─→ сравнение
Firebird S_ULIC ───┘

s_dom.csv → S_OPUTERHOUSES → Firebird
```
 
## Этапы
```text
Получить внешние CSV-файлы.
Прочитать данные CSV.
Прочитать соответствующие данные из Firebird.
Подготовить данные для сравнения.
Сравнить данные внешнего источника с Firebird.
Определить различия:
новые объекты;
изменённые объекты;
отсутствующие объекты;
объекты, для которых требуется дополнительная проверка.
Сформировать результат сравнения для дальнейшей обработки.
```

Объекты текущей синхронизации
| Внешний источник | таблица  Firebird | Синхронизация | Залить вбазу |
|-----------------|--------------------|---------------|--------------|
| s_vidul.csv     |	S_VIDUL	           | Да            | Да           |
| s_ulic.csv	  |   S_ULIC	       | Да            | Да           |
| s_dom.csv	      |   —                | Нет           | Да           |
| Районы  	      | S_RAYON   	       | Нет           | Нет          |

# Что пока не определено 

Соответствия между идентификаторами внешнего источника и идентификаторами
Firebird пока не определены.

Правила определения соответствий, обработки новых объектов и записи
изменений в основную БД будут определены на следующих этапах проекта.

# Детальный Поток обработки внешних адресных данных

## 1. Общая схема

Данные поступают из внешних CSV-файлов и обрабатываются отдельно
для типов улиц, улиц и домов.

Основные этапы:

1. Получение CSV-файлов.
2. Загрузка данных во временные таблицы.
3. Проверка загруженных данных.
4. Подтверждение загрузки.
5. Перенос данных во входные постоянные таблицы.
6. Очистка временных таблиц.
7. Запись сведений о загрузке в S_INPUT_LOAD.

## 2. Обработка типов улиц

Типы улиц загружаются из файла s_vidul.csv.

1. Прочитать данные из CSV.
2. Проверить корректность идентификаторов и названий.
3. Сопоставить типы улиц по внешним идентификаторам.
4. После подтверждения обновить данные в S_INPUT_VIDUL.
5. Попытаться составить сведение 
6. все что получилось в свести добавить в таблицу седения

Для типов улиц отдельная временная таблица не используется.

## 3. Обработка улиц

Улицы загружаются из файла s_ulic.csv.

1. Прочитать данные из CSV.
2. Загрузить данные во временную таблицу TMP_INPUT_ULIC.
3. Проверить корректность идентификаторов улиц и типов.
4. Проверить наличие соответствующих типов улиц.
5. Сопоставить улицы по внешним идентификаторам.
6. После подтверждения перенести данные в S_INPUT_ULIC.
7. Очистить TMP_INPUT_ULIC.
8.Попытаться составить сведение 
9.все что получилось в свести добавить в таблицу седения

Внешний идентификатор улицы используется для её сопоставления
между загрузками.

## 4. Обработка домов

Дома загружаются из файла s_dom.csv.

1. Прочитать данные из CSV.
2. Загрузить данные во временную таблицу TMP_INPUT_DOM.
3. Проверить корректность идентификаторов домов и улиц.
4. Проверить наличие соответствующих улиц по EXT_STREET_ID.
5. Сопоставить дома по внешним идентификаторам.
6. После подтверждения перенести данные в S_DOM_EXT.
7. Очистить TMP_INPUT_DOM.

Дома связываются с улицами по внешнему идентификатору улицы.

Название улицы и тип улицы в S_DOM_EXT не дублируются.
Если название улицы изменяется в источнике, дом остаётся связанным
с этой улицей по EXT_STREET_ID.

## 5. Журнал загрузок

После успешного завершения загрузки в S_INPUT_LOAD сохраняются:

- тип загруженных данных;
- имя исходного файла;
- дата и время загрузки.

Содержимое CSV-файлов и большие объёмы исходных данных в журнале
не хранятся.

## 6. Очистка временных таблиц

После подтверждения и переноса данных временные таблицы очищаются.

Временные таблицы используются только для текущей загрузки
и не предназначены для хранения истории.

## 7. Границы текущей реализации

На текущем этапе:

- автоматическое обновление существующих таблиц адресов не выполняется;
- автоматическое сопоставление домов с существующими домами не выполняется;
- история изменений отдельных записей не хранится;
- журнал загрузок содержит только метаданные файлов.
