# Первый экран 

## Режи просмотра

### Колонки для  вкладки «Типы улиц»

**Основная таблица (`S_VIDUL`)**
- Код  - `ID`
- Полное название -`FULLNAME`
- Сокращение - `NAME_UA`

**Входная таблица (`S_INPUT_VIDUL`)**
- Код `EXT_ID`
- Полное название `NAME`
- Сокращение `SHORT_NAME`


(Ищем соответствие `S_VIDUL.ID `=  `S_INPUT_VIDUL.FK_ID_VIDUL`)

**Служебные**
- Статус сведения (Сведён / Только основная / Только входная)
- № строки

Пример структуры таблицы:
|   | Основная таблица                            |  Внешний источник                              |                 |
|---|---------------------------------------------|------------------------------------------------|-----------------|
| № | Код (осн.) | Название (осн.) | Сокр. (осн.) | Код (вход.) | Название (вход.) | Сокр. (вход.) | Статус          |
|---|------------|-----------------|--------------|-------------|------------------|---------------|-----------------|
| 1 | G          | ПРОСПЕКТ        | ПРОСП.       | G           | ПРОСПЕКТ         | ПРОСП.        | Сведён          |
| 2 | D          | ПРОВУЛОК        | ПРОВ.        |             |                  |               | Только основная |
| 3 |            |                 |              | X           | НОВЫЙ ТИП        | НОВ.          | Только входная  |
