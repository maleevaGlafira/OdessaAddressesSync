# Загрузка типов улиц

## Назначение

Экран предназначен для загрузки данных типов улиц
из внешнего CSV-файла `s_vidul.csv`, их проверки,
сохранения новых и изменённых записей и последующего
сопоставления с таблицей `S_VIDUL`.

---

## 1. Начальное состояние

При открытии вкладки «Типы улиц» пользователь может
переключиться в режим «Загрузка».

В начальном состоянии файл не выбран.

Отображаются:

- поле выбора файла;
- информация о требуемом формате;
- кнопка «Проверить файл» — неактивна.

---

## 2. Выбор файла

Пользователь выбирает файл `s_vidul.csv`.

После выбора отображаются:

- имя файла;
- размер файла;
- кнопка «Удалить»;
- кнопка «Проверить файл».

Кнопка «Проверить файл» становится активной.

---

## 3. Проверка файла

После нажатия «Проверить файл» выполняется последовательность
проверок.

### 3.1 Проверка структуры CSV

Проверяется:

- формат файла;
- кодировка;
- разделитель;
- наличие заголовков;
- наличие обязательных колонок;
- соответствие типов данных ожидаемым типам.

Требования к структуре входного файла определены в
`docs/.../inputCsv.md`.

Если проверка структуры не пройдена,
данные в базу не записываются.

Пользователю отображается сообщение об ошибке.

### 3.2 Проверка данных

После успешной проверки структуры выполняется проверка
значений строк в соответствии с правилами проекта.

Правила проверки определяются в `data-flow.md`.

Для каждой ошибочной строки сохраняются:

- номер строки CSV;
- значения полей;
- описание ошибки.

При наличии ошибок пользователь видит таблицу ошибок.

## 4. Определение новых и изменённых записей

После успешной проверки данных каждая запись CSV сравнивается
с существующей записью `S_INPUT_VIDUL` по `EXT_ID`.

### Новая запись

Если `EXT_ID` отсутствует в `S_INPUT_VIDUL`,
запись считается новой.

### Изменённая запись

Если `EXT_ID` существует, сравниваются:

- `NAME`;
- `SHORT_NAME`.

Если хотя бы одно значение отличается,
запись считается изменённой.

### Запись без изменений

Если `EXT_ID`, `NAME` и `SHORT_NAME` соответствуют
существующей записи, запись повторно не загружается.

## 5. Результат проверки

После проверки отображается сводка:

- всего строк в файле;
- новых записей;
- изменённых записей;
- записей без изменений;
- ошибочных записей.

Если имеются ошибки, отображается таблица ошибочных строк.

Если ошибок нет, пользователь может подтвердить загрузку.

Кнопка:

**«Подтвердить и загрузить»**

## 6. Сопоставление
Кнопка *синхронизация*
После загрузки выполняется сопоставление `S_INPUT_VIDUL`
с `S_VIDUL`.

Для сопоставления используются правила из `rules.md`.

Результатом сопоставления является:

- заполненный `FK_ID_VIDUL`, если соответствие найдено;
- отсутствие `FK_ID_VIDUL`, если соответствие не определено.

После завершения сопоставления пользователь может
перейти в режим «Просмотр».
