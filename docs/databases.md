## 3 Роль баз

Добавить таблицу
Типы адресных обьектов Obj_Types (id name)
"Список адресных таблиц" Tables_List (id name desription is_outer isneedsinh fk_TL_AddressObjtypes)
Между внешними обьектами Firebird добавить таьлицу связей S_SSVED
Для улиц, районов соответствия хранятся в таблице MSSQL.S_STREETSSVED.

В Firebird существуют соответствующие справочники, однако физические связи между базами через FOREIGN KEY отсутствуют.

- районы S_REGIONS;
- типы улиц S_STREETTYPES;
- улицы S_STREETS.

Таблица S_STREETSSVED используется для хранения соответствий между объектами MSSQL и подключенными базами.
