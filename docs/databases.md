# Архитектура баз данных АВР

## 1. Общая архитектура

Система состоит из нескольких информационных систем, использующих разные СУБД.

### Базы данных

| БД           | СУБД     | Назначение                                        | Описание архитектуры        |
| ------------ | -------- | ------------------------------------------------- | --------------------------- |
| `avarodessa` | Firebird | База программы «Диспетчер АВР» воды и канализации | /database-model/firebird.md |

## 2. Базы данных

### 2.1 Firebird

**Сервер:** `127.0.0.1`  
**База данных:** `avarodessa`  
**СУБД:** Firebird  
**Программа:** «Диспетчер АВР» воды и канализации

**Учетная запись:** `sysdba`

Пароль хранится отдельно и не включается в документацию.



### Адреса

Улицы хранятся отдельно от данных домов/адресов.
