### 3.1 Таблица S_RAYON

**Назначение:** справочник районов.

| Поле    | Тип         | NULL | Назначение                          | Использование                         |
| ------- | ----------- | ---- | ----------------------------------- | ------------------------------------- |
| ID      | int         | NO   | Уникальный идентификатор района     | Используется                          |
| NAME_R  | char(20)    | NO   | Название района на русском языке    | Используется                          |
| del     | char(1)     | NO   | Признак активности                  | Если район не активен — "d" иначе "-" |
| NAME_UA | varchar(20) | YES  | Название района на украинском языке | Используется                          |

**Первичный ключ:** `ID`

### 3.2 Таблица S_VIDUL

**Назначение:** справочник типов улиц.

| Поле     | Тип         | NULL        | Назначение                                                   | Использование                              |
| -------- | ----------- | ----------- | ------------------------------------------------------------ | ------------------------------------------ | ------------------------------------------------- |
| ID       | int         | NO          | Уникальный идентификатор типа улицы                          | Используется                               |
| NAME_R   |             | varchar(20) | NO                                                           | Сокращенное название типа на русском языке | Фактически содержит названия типа, например «УЛ.» |
| DEL      | char(1)     | NO          | Признак активности                                           | Если тип активен — "-" иначе d             |
| FULLNAME | varchar(24) | NO          | Полное название типа типа на русском языке, например «улица» | НеИспользуется                             |
| NAME_UA  | varchar(24) | YES         | Сокращенное название типа на украинском языке например ВУЛ.  | Используется                               |

**Первичный ключ:** `ID`

**Связи:**

`S_STREETS.FK_STREETS_STREETTYPES → S_VIDUL.ID`

**Пример:**

Улица «Пушкинская» может иметь:

`S_ULIC.ID_VIDUL = S_VIDUL.ID`

где соответствующий тип — «улица» / «УЛ.».

### 3.3 Таблица S_ULIC

**Назначение:** справочник улиц.

| Поле     | Тип         | NULL | Назначение                         | Использование                  |
| -------- | ----------- | ---- | ---------------------------------- | ------------------------------ |
| ID       | int         | NO   | Уникальный идентификатор улицы     | Используется                   |

| WWW_XY   | varchar(24) | YES  | Не используется                    | Пустое везде                   |
| DEL      | char(1)     | NO   | Признак активности                 | Если тип активен — "-" иначе d |
| NAME_R   | varchar(40) | NO   | Название улицы на русском языке    | Используется                   |
| NAME_UA  | varchar(70) | NO   | Название улицы на украинском языке | Используется                   |

**Первичный ключ:** `ID`

**Связи:**

`S_ULIC.ID_VIDUL → S_VIDUL.ID`

**Логическая структура:**

S_VIDUL  
↓  
S_ULIC

Одна запись `S_VIDUL` может соответствовать многим улицам.

_Планирую создать_

**Назначение:** таблица сведения пипы типов объектов.

↓
