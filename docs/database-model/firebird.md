## Таблицы входных данных

Таблицы предназначены для хранения данных, полученных из внешних CSV-файлов.

Входные данные используются для последующего сопоставления с существующими
справочниками Firebird.

### S_INPUT_VIDUL

**Назначение:** справочник типов улиц из внешнего источника.

Источник: `s_vidul.csv`.

| Поле      | Тип          | NULL | Назначение                                      | Использование |
|-----------|--------------|------|-------------------------------------------------|---------------|
| ID        | int          | NO   | Уникальный внутренний идентификатор записи      | Первичный ключ |
| EXT_ID    | char(1)      | NO   | Символьный код типа улицы во внешнем источнике  | Сопоставление с внешними данными |
| NAME      | varchar(20)  | NO   | Полное название типа улицы                     | Используется |
| SHORT_NAME| varchar(10)  | NO   | Сокращённое название типа улицы                 | Используется |

- `ID` — первичный ключ.
- `EXT_ID` — внешний символьный код типа улицы.

**Логическая связь:**

`S_INPUT_VIDUL.EXT_ID → S_INPUT_ULIC.EXT_TYPE_ID`

Один тип улицы может соответствовать многим улицам.

### S_INPUT_ULIC

**Назначение:** справочник улиц из внешнего источника.

Источник: `s_ulic.csv`.

| Поле       | Тип          | NULL | Назначение                                      | Использование |
|------------|--------------|------|-------------------------------------------------|---------------|
| ID         | int          | NO   | Уникальный внутренний идентификатор записи      | Первичный ключ |
| EXT_ID     | int          | NO   | Идентификатор улицы во внешнем источнике        | Сопоставление с внешними данными |
| EXT_TYPE_ID| char(1)      | NO   | Символьный код типа улицы                       | Связь с `S_INPUT_VIDUL.EXT_ID` |
| NAME       | varchar(150) | NO   | Название улицы                                  | Используется |
| is_sved    | char(1)      | YES  | Если не пусто то нужно свести                   | Используется |
- `ID` — первичный ключ.
- `EXT_ID` — внешний идентификатор улицы.
- `NAME` — название улицы из внешнего источника.

**Связи:**

Логическая связь:

`S_INPUT_ULIC.EXT_TYPE_ID → S_INPUT_VIDUL.EXT_ID`

Физическая связь (FK) не предполагается на текущем этапе.

### S_DOM_EXT

**Назначение:** таблица домов из внешнего источника.

Источник: `s_dom.csv`.

Единственная постоянная таблица домов проекта. Не сводится с существующими
таблицами домов Firebird.

| Поле          | Тип         | NULL | Назначение                                 | Использование |
|---------------|-------------|------|--------------------------------------------|---------------|
| ID            | int         | NO   | Уникальный внутренний идентификатор записи | Первичный ключ |
| EXT_ID        | int         | NO   | Идентификатор дома во внешнем источнике    | Сопоставление домов |
| EXT_STREET_ID | int         | NO   | Идентификатор улицы во внешнем источнике   | Связь с `S_INPUT_ULIC.EXT_ID` |
| HOUSE_NUMBER  | varchar(10) | NO   | Номер дома                                 | Используется |
| CORPUS        | varchar(10) | YES  | Номер корпуса                              | Используется |

- `ID` — первичный ключ.
- `EXT_ID` — внешний идентификатор дома.
- `EXT_STREET_ID` — внешний идентификатор улицы, к которой относится дом.

**Связи:**

Логическая связь:

`S_DOM_EXT.EXT_STREET_ID → S_INPUT_ULIC.EXT_ID`

Одна улица может соответствовать многим домам.

Название улицы и тип улицы в `S_DOM_EXT` не дублируются.
При изменении названия улицы дом остаётся связанным с ней по внешнему
идентификатору.

### S_INPUT_LOAD

**Назначение:** журнал загрузок входных файлов.

Хранит только сведения о загрузке, без содержимого файлов.

| Поле      | Тип          | NULL | Назначение                     | Использование |
|-----------|--------------|------|--------------------------------|---------------|
| ID        | int          | NO   | Уникальный идентификатор записи| Первичный ключ |
| DATA_TYPE | varchar(20)  | NO   | Тип загруженных данных         | VIDUL, ULIC или DOM |
| FILE_NAME | varchar(255) | NO   | Имя исходного файла            | Используется |
| LOAD_DATE | timestamp    | NO   | Дата и время загрузки          | Используется |

### Временные таблицы

Временные таблицы используются для загрузки и проверки данных перед
переносом в постоянные таблицы.

#### TMP_INPUT_ULIC

**Назначение:** временное хранение улиц из `s_ulic.csv`.

| Поле        | Тип          | NULL | Назначение                                |
|-------------|--------------|------|-------------------------------------------|
| EXT_ID      | int          | NO   | Идентификатор улицы во внешнем источнике  |
| EXT_TYPE_ID | char(1)      | NO   | Символьный код типа улицы                 |
| NAME        | varchar(150) | NO   | Название улицы                            |
| LOAD_ID | INTEGER | Идентификатор загрузки из S_INPUT_LOAD |

#### TMP_INPUT_DOM

**Назначение:** временное хранение домов из `s_dom.csv`.

| Поле          | Тип         | NULL | Назначение                                |
|---------------|-------------|------|-------------------------------------------|
| EXT_ID        | int         | NO   | Идентификатор дома во внешнем источнике   |
| EXT_STREET_ID | int         | NO   | Идентификатор улицы во внешнем источнике  |
| HOUSE_NUMBER  | varchar(10) | NO   | Номер дома                                |
| CORPUS        | varchar(10) | YES  | Номер корпуса                             |
| LOAD_ID | INTEGER | Идентификатор загрузки из S_INPUT_LOAD |

Временные таблицы используются только для текущей загрузки.
После проверки и подтверждения данные переносятся в постоянные таблицы,
после чего временные таблицы очищаются.

S_DOM_EXT
