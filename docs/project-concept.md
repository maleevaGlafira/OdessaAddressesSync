# Концепция проекта

Проект предназначен для загрузки внешних данных адресного плана,
их сравнения с данными Firebird, выявления расхождений и последующей
загрузки проверенных данных в базу.

Основные этапы:

1. Получение внешних данных.
2. Загрузка и подготовка данных.
3. Сравнение с Firebird.
4. Обработка расхождений.
5. Проверка пользователем.
6. Проверка данных перед записью.
7. Загрузка подтверждённых данных в Firebird.
