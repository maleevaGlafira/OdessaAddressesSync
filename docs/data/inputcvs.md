# Входные CSV-файлы

Внешний источник данных предоставляет информацию об адресном плане в виде CSV-файлов.

Файлы используются как входные данные для анализа и синхронизации справочников улиц и типов улиц с базой Firebird.

## Формат файлов

* Формат: CSV
* Разделитель полей: `;`
* Текстовые значения могут быть заключены в двойные кавычки `"`.
* Кодировка: UTF-8.
* Первая строка содержит названия полей.
* Пустое значение обозначается пустым полем.

## Файлы

### `s_vidul.csv` — типы улиц

Содержит справочник типов улиц.

| Поле                          | Описание                                       | Тип 
| ----------------------------- | ---------------------------------------------- |-----
| `код типу вулиці`             | Уникальный код типа улицы во внешнем источнике | Символ
| `назва типу вулиці`           | Полное название типа улицы                     | Строка
| `скорочена назва типу вулиці` | Сокращённое название типа улицы                | Строка

Пример:

```csv
код типу вулиці;назва типу вулиці;скорочена назва типу вулиці
"G";"ПРОСПЕКТ";"ПРОСП."
"D";"ПРОВУЛОК";"ПРОВ."
```

Код типа улицы используется в `s_ulic.csv` для определения типа улицы.

---

### `s_ulic.csv` — улицы

Содержит справочник улиц.

| Поле                          | Описание                                  | Тип
| ----------------------------- | ----------------------------------------- | ----
| `код вулиці`                  | Уникальный код улицы во внешнем источнике | Число
| `код типу вулиці`             | Код типа улицы из `s_vidul.csv`           | Символ
| `скорочена назва типу вулиці` | Сокращённое название типа улицы           | Строка
| `назва вулиці`                | Название улицы                            | Строка

Пример:

```csv
код вулиці;код типу вулиці;скорочена назва типу вулиці;назва вулиці
0;"0";"*";"*"
2;"A";"БУЛ.";"ФРАНЦУЗЬКИЙ"
5;"D";"ПРОВ.";"1-Й АМБУЛАТОРНИЙ"
```

Связь с `s_vidul.csv`:

```text
s_ulic.код типу вулиці
        ↓
s_vidul.код типу вулиці
```

Таким образом, одна запись типа улицы из `s_vidul.csv` может использоваться несколькими улицами из `s_ulic.csv`.

---

### `s_dom.csv` — дома

Содержит адреса домов, связанные с улицами.

Данные домов **не участвуют в текущей синхронизации**. Файл описывается как входной источник данных, который может использоваться в дальнейшем.

| Поле                          | Описание                                 | тип
| ----------------------------- | ---------------------------------------- | --------
| `код будинку`                 | Уникальный код дома во внешнем источнике | Число
| `код вулиці`                  | Код улицы из `s_ulic.csv`                | число
| `код типу вулиці`             | Код типа улицы                           | символ
| `скорочена назва типу вулиці` | Сокращённое название типа улицы          | строка
| `назва вулиці`                | Название улицы                           | строка
| `номер будинку`               | Номер дома                               | строка
| `корпус`                      | Номер корпуса, если указан               | строка

Пример:

```csv
код будинку;код вулиці;код типу вулиці;скорочена назва типу вулиці;назва вулиці;номер будинку;корпус
2;2;"A";"БУЛ.";"ФРАНЦУЗЬКИЙ";"1";""
3;2;"A";"БУЛ.";"ФРАНЦУЗЬКИЙ";"17";""
```

Связь с улицами:

```text
s_dom.код вулиці
       ↓
s_ulic.код вулиці
```

Таким образом, одна улица может иметь несколько домов.

## Связи между файлами

Логическая структура входных данных:

```text
s_vidul.csv
    │
    │ код типу вулиці
    ▼
s_ulic.csv
    │
    │ код вулиці
    ▼
s_dom.csv
```

### Текущий статус использования

| Файл          | Назначение                       | Участвует в текущей синхронизации | Нужно добавтьб с базу
| ------------- | -------------------------------- | --------------------------------- | ---------------------
| `s_vidul.csv` | Типы улиц                        | Да                                | Да
| `s_ulic.csv`  | Улицы                            | Да                                | Да
| `s_dom.csv`   | Дома                             | Нет                               | Да 
| Районы        | Внешний CSV-источник отсутствует | Нет                               | нет

## Важные ограничения

* Районы не входят в текущий внешний CSV-источник и сейчас не синхронизируются.
* Дома (`s_dom.csv`) не синхронизируются на текущем этапе. Но добавить в базу нужно
* Основными объектами текущей синхронизации являются **типы улиц и улицы**.
* Коды во внешних CSV являются идентификаторами внешнего источника и не следует автоматически считать идентификаторами объектов Firebird.
